## 作り

- **`_build/` の Python がHTMLを書き出す。**HTMLを直接いじらない。**直すのは `_build/` の側**（`common.py` が共通レイアウト、`b_top.py` `b_products.py` `b_company.py` `b_other.py` が各ページ、`data_*.json` が中身）
- ビルドは `python3 _build/build.py` の一発。**依存パッケージなし**
- CSSとJSは `assets/` で53ページ共通。CSS 42KB、JS 7KB
